# 보훈데이터 아케이드 현행 구현 기준

이 문서는 최초 기획서 이후 리뷰와 UI 확인 과정에서 확정된 변경을 기록한다. 기존 문서와 충돌하는 항목은 아래 현행 기준을 우선한다.

## 공통 UX

- 홈에서 게임을 선택하면 게임 화면으로 이동한 뒤 설명 오버레이와 3초 카운트다운을 보여준다.
- 모바일·태블릿 게임 HUD에는 뒤로가기를 두지 않고 일시정지 버튼만 둔다.
- 일시정지 메뉴는 `메인화면 가기`, `이어서 하기`, `다시하기`를 제공한다.
- 일반 브라우저 새로고침은 메인으로 보내되, 일시정지 메뉴의 `다시하기`는 현재 게임을 초기화한다.
- 결과 상세는 게임 직후에만 보여주며 새로고침 후 복원하지 않는다. 최고점과 등급은 localStorage로 유지한다.

## 게임① 가장 가까운 위탁병원 찾기

> 과거 "핀을 지도에 직접 찍는 위치감각게임"에서 객관식 방식으로 개편되었다. 지도에 배치된 병원 후보(정답 1개 + 오답 최대 4개) 중 하나를 탭해서 고르는 게임이며, 자유 클릭 좌표를 채점하는 로직 자체가 없다.

- 5라운드 진행, 라운드 제한시간은 5초다.
- 시간 초과 시에는 그 시점까지 선택해 둔(확인 버튼을 누르지 않은) 후보를 그대로 채점하며, 아무것도 선택하지 않았을 때만 0점 처리한다.
- 점수는 거리 비율이 아니라 실제 거리 순위 기반 고정 점수(1등 100 / 2등 60 / 3등 30 / 4등 10 / 5등 0)를 사용한다.
- 후보 핀만 클릭 가능한 구조라 "육지 경계 밖 클릭"이라는 입력 자체가 존재하지 않는다.
- 결과 화면은 라운드별 지역명·정답 병원명·획득 점수만 보여주고, 실제 거리(km) 수치와 미니맵은 표시하지 않는다.
- "평균 오차(km)"라는 지표는 없다. 결과 통계는 총점·진행 라운드 수·정답 라운드 수만 제공한다.

## 게임② 의료비 감각 테스트

> "찐병원 가짜병원"(병원명 O/X 퀴즈)은 전면 개편으로 완전히 폐지되었다. `reviewed` 필드와 O/X 판정 로직은 더 이상 코드에 존재하지 않는다. 지금은 비급여 진료비 데이터를 다루는 5종 라운드로 구성된 "의료비 감각 테스트"다.

- 5라운드 고정, 라운드당 최대 100점, 총 500점 만점이다.
- 라운드 유형은 매번 다음 순서로 진행된다.
  1. **슬라이더**: 로그 스케일 슬라이더(1만~120만 원)로 실제 비급여 수가를 추정. 오차율 기준 5단계 채점(≤10% 100점, ≤25% 70점, ≤40% 40점, ≤70% 15점, 그 외 0점).
  2. **가격대 맞추기**: 로그 사다리 기반 4지선다 가격대 카드에서 정답을 고른다. 맞으면 100점, 틀리면 0점.
  3. **순서 맞추기**: 4개 항목을 드래그로 가격 오름차순 정렬. 맞힌 위치 수에 따라 0/20/50/100점 단계 채점.
  4. **예산 안에 담기**: 5개 항목 중 예산 안에 드는 항목을 전부 골라야 하며, 오답·누락 여부에 따라 0/20/50/100점 단계 채점.
  5. **가격 비교**: 두 항목 중 더 비싼 쪽 맞히기. 정답 100점, 오답 0점.
- 슬라이더 라운드 결과에는 "내 예상 / 공개 비급여 수가 / 차이·오차율" 통계 카드를 보여준다.
- 최종 결과에는 총점, 100점(적중) 라운드 수, 라운드별 결과 배지가 표시된다.
- 가격이 만원 단위로 딱 떨어지는 경우 정답을 로그 사다리 값으로 뭉개 표시하던 문제를 수정했다. 지금은 그런 경우 실제 가격을 그대로 정답으로 쓰고, 오답 3개의 라벨 형식(약 접두어 유무)도 함께 맞춰 정답이 눈에 띄지 않게 한다.

## 게임③ 용어 짝맞추기

- PC 카드 배치는 "최대 3행" 원칙이 사용자 피드백("세로로 봤을 때 카드가 4장씩 있어야 한다")에 따라 뒤집혔다. 12장(라운드1)은 4열 3행이지만, 16장(라운드2)은 4열 4행, 20장(라운드3)은 5열 4행으로 배치한다.
- 점수 환산식은 아직 밸런스 조정 대상이지만, 시간과 오매칭이 늘수록 점수가 낮아지고 100~500점을 보장한다.

## 배포·데이터

- Vercel은 모든 경로를 `index.html`로 rewrite해 SPA 404를 방지한다.
- 정적 JSON 3종은 앱 시작 시 필드 타입, 좌표 범위, ID 중복, 최소 게임 구성 수량을 검증한다.
- 게임 중 외부 공공 API를 호출하지 않는다.
