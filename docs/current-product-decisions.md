# 보훈데이터 아케이드 현행 구현 기준

이 문서는 최초 기획서 이후 리뷰와 UI 확인 과정에서 확정된 변경을 기록한다. 기존 문서와 충돌하는 항목은 아래 현행 기준을 우선한다.

## 공통 UX

- 홈에서 게임을 선택하면 게임 화면으로 이동한 뒤 설명 오버레이와 3초 카운트다운을 보여준다.
- 모바일·태블릿 게임 HUD에는 뒤로가기를 두지 않고 일시정지 버튼만 두다.
- 일시정지 메뉴는 `메인화면 가기`, `이어서 하기`, `다시하기`를 제공한다.
- 일반 브라우저 새로고침은 메인으로 보내되, 일시정지 메뉴의 `다시하기`는 현재 게임을 초기화한다.
- 결과 상세는 게임 직후에만 보여주며 새로고침 후 복원하지 않는다. 최고점과 등급은 localStorage로 유지한다.

## 게임① 위치감각게임

- 라운드 제한시간은 8초다.
- 시간 초과는 미확정 핀을 인정하지 않고 0점으로 처리한다.
- 점수는 절대 10/50/100km 기준이 아니라 해당 지역 지도 반경 대비 오차 비율을 사용한다.
- 육지 경계 밖 클릭은 위치 입력으로 인정하지 않는다.
- 결과 화면은 라운드별 거리·점수 요약만 보여주고 미니맵은 제공하지 않는다.
- 평균 오차는 시간 초과 라운드를 제외하고 계산한다.

## 게임② 찐병원 가짜병원

- `reviewed=true`는 수동 승인이 아니라 원본 공단 병원명과의 자동 중복 대조 통과를 의미한다.
- O/X 버튼은 모바일에서 양쪽으로 넓게 배치하고 124px 원형 터치 영역을 사용한다.
- 하단 규칙 설명과 `총 20문항/정답당 25점/최대 500점` 칩은 중복 정보로 보아 표시하지 않는다.

## 게임③ 용어 짝맞추기

- PC에서 카드를 최대 3행으로 배치한다: 12장 4열, 16장 6열, 20장 7열.
- 점수 환산식은 아직 밸런스 조정 대상이지만, 시간과 오매칭이 늘수록 점수가 낮아지고 100~500점을 보장한다.

## 배포·데이터

- Vercel은 모든 경로를 `index.html`로 rewrite해 SPA 404를 방지한다.
- 정적 JSON 3종은 앱 시작 시 필드 타입, 좌표 범위, ID 중복, 최소 게임 구성 수량을 검증한다.
- 게임 중 외부 공공 API를 호출하지 않는다.
